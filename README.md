# InfraScan

AI-powered infrastructure defect detection: mobile capture → dedup/ingest → tiered vision-model inference → calibrated human review → GIS dashboard.

Monorepo: `/frontend` (React + Vite, Vercel), `/backend` (FastAPI, Render), `/docs` (design + operational docs).

Full build sequence and architecture decisions: see `infrascan_deployment_playbook.md`.
